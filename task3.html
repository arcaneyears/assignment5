Task 3. Changing Styles

Part 2. DOM Manipulation

This block changes its background color and the size of this text.

How it works

The block is changed through its style object. The first button writes a new value into style.backgroundColor, the other two change style.fontSize. The font size is stored in a variable so that each click adds or removes two pixels.
