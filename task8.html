Task 8. Interactive To-Do List

Part 4. Mini Project

Please write the task first.

    No tasks yet.

    How it works

    • Every task is an object with a text and a done field, stored in the array tasks.
    • After each change the list is drawn again from that array.
    • A click on the text switches the done field and the item gets a strike-through style.
    • The Delete button removes the task from the array with splice().
    • Nothing is saved after a reload, the data lives only in the array.
